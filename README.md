# light3cpp
light3cpp is a lightweight C/C++ 3D engine built for games created in make. at under 4mb, it is a fully capable engine that handles the heavy lifting so you only have to write the game code.

## features:
- loads and properly renders any .glb or .obj file
- currently runs on opengl
- vulkan and metal wrapper support planned for the future
- openXR branch
- Works on Windows, Mac, Linux, BSD, SteamOS, Gamecube, and Standalone VR headsets that support OpenXR (Oculus Quest, Pico, and Steam Frame).

## templates:
the engine includes a template 3d platformer and a kart racing demo to show what it can do right out of the box.

developed by dream tech studios.
